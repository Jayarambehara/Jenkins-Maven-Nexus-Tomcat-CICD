# Jenkins-Maven-Nexus-Tomcat-CICD

# End-to-End CI/CD Pipeline

## Tools Used
- GitHub
- Jenkins
- Maven
- Nexus
- Tomcat

## Pipeline Flow

GitHub → Jenkins → Maven → Nexus → Tomcat

## Project Description

Implemented an automated CI/CD pipeline where source code is pulled from GitHub, built using Maven, stored in Nexus Repository Manager, and deployed automatically to Apache Tomcat using Jenkins.
